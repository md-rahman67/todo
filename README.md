# TAYO – Todo App

TAYO is a simple and responsive Todo app built to organize and manage daily tasks with an interactive user interface.

### Features
- Create, edit, and delete Todo lists.
- Add and delete tasks within Todo lists.
- Bootstrap modal popups for adding tasks and confirming deletions.
- Collapsible and interactive UI components.
- Responsive design with Bootstrap.
- Dark-themed interface with Font Awesome icons.
- Confirmation prompts to prevent accidental deletion.

### Tech Stack
- Node.js & Express.js
- MongoDB & Mongoose
- EJS
- Bootstrap
- HTML & CSS

### Installation
1. Clone this repository.
2. Run `npm install`.
3. Start the server using `node app.js`.
4. Open `http://localhost:3000` in your browser.
